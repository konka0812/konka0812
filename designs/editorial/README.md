## 01 &nbsp;·&nbsp; 关于 <sub>ABOUT</sub>

在郑州写代码，主要做 AI Agent 工具链——把模型、提示词、插件和一堆零散脚本收进同一条流水线，让它们安静地自己跑完。
<br />
也写全栈 Web 和 PWA：能离线打开、能装进手机桌面那种。偶尔把 Three.js 拉进来，给页面加一点不必要但好看的动效。
<br />
喜欢边界清楚的东西。一个文件做一件事，一个函数只说一句话。做得不快，但尽量做得能一直用下去。
